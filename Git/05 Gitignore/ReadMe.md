### Git .gitignore &mdash;

git ပေါ်မတင်ချင်တဲ့ ဖိုင်တွေကို ဖယ်ထားချင်ရင် .gitignore အသုံးပြု၍ ဖယ်ထားလို့ရပါတယ်။

```sh
    touch .gitignore
    vim .gitignore
    # press i
    # type filename.txt
    # type foldername

    # Compiled Sources #
    ####################
    # *.com
    # *.class
    # *.dll
    # *.exe
    # *.xlsx

    # Packages #
    # *.zip
    # *.rar
    # *.tar
    # *.7zip
    # *.dmg
    # *.iso

    # Images Sources #
    # *.jpeg
    # *.png
    # *.ico

    rm .gitignore # Delete .gitignore file
```
