### Git Commit &mdash;

```sh
    git restore --staged file_name.ext/*

    git reset file_name.ext/*
```

### Collect Commit &mdash;

```sh
    git reset --soft HEAD
    git status
    git commit -m "commit message"
```

```sh
    git rebase -i HEAD

    # pick
    # squash or s - collect
    # drop or d - delete
```

### Delete commit and files &mdash;

```sh
    git reset --hard HEAD
```

### Show Commit History &mdash;

```sh
    git reflog
```
