### Git Lesson - 02 &mdash;

```sh
    git init "folder name"
    cd foldername       # Enter folder
    ls                  # Linux or Mac OS
    dir                 # Windows OS
    git config --global init.defaultbranch main
    git branch -M main
    git status
    git add -A          # add all file to staging area
    git commit -m "commit name"

    git log --all --oneine # all means all branch and --oneline means all of repostitory by oneline
```

`NOTE` : local repo ထဲ ထည့်ပြီးနောက်ပိုင်း branch တွေကို တည်ဆောက်ခဲ့ရင် branch အသစ်တွေမှာ အရင်ထည့်ထားသော file တွေအကုန် ပါပီးသားဖြစ်ပါတယ်။
