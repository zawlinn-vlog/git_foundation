### Git Branch &mdash;

#### Create Branch

> branch တစ်ခုတည်ဆောက်တော့မယ်ဆိုရင် main/master branch ထဲမှာ ကနဦးသိမ်းဆည်းထားသော ဖိုင်တစ်ခုခု အနည်းဆုံးရှိရမယ်။

```sh
    touch test.txt
    git add test.txt
    git commit -m "Add test file"

    git branch branchname
    git checkout -b branchname # Create branch and Switch to new Branch

    git branch # check branches
    git checkout branchname # switch branch
```

#### Rename Branch

> နာမည်ပြောင်းချင်တဲ့ branch ကို switch အရင်လုပ်ပါ။

```sh
    git checkout branchname
    git branch -m newbranchname
    git branch -m oldbranchname newbranchname
```

#### Delete Branch

> current မဟုတ်တဲ့ branch ကို အရင် switch လုပ်ပါ။

```sh
    git checkout branchname
    git branch --delete branchname
    git branch -d branchname
    git branch -D branchname
    git branch # check branches
```

> git diff သည် ‌staging area မရောက်ခင်သာ အလုပ်လုပ်သည်။

```sh
    git status
    git status -s # condition M for modified(edit) and A for Add(new)
    git diff # show Diff of Modified file

    git diff master new-features
    git diff new-features master
```
