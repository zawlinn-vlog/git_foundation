### Git Lesson - 01 &mdash;

```sh
    git init "folder name"  # git init and create folder

    git init                # git init

    git status              # check

    git config --global init.defaultBranch main # Set Default Branch Main

```

### Check Folder Dir &mdash;

```sh
    dir     # for Window
    ls      # for Linux or Mac
    ls -al  # for LInux or Mac
```

### Create txt File (Linux and Mac)

```sh
    vim "filename.txt"
    i       # for typing
    esc     # quite
    :wq     # Enter
```

`git add .` သည် working Directory ကနေ staging area သို့ ပြောင်းလဲပေးသည်။

`git commit -m name` သည် staging area ကနေ local repository ထဲသို့ ပြောင်းလဲပေးသည်။

| State 1           | State 2      | State 3          | State 4           |
| ----------------- | ------------ | ---------------- | ----------------- |
| Working Directory | Staging Area | Local Repository | Remote Repository |

```sh
    git status      # Checking file
    git add .       # Add all File
    git add -a      # Add all file
```

### Staging Area to Local Repository

```sh
    git commit -m "commit name"
```

Checking log files

```sh
    git log
    git log --oneline
```

### Creating New Branch &mdash;

```sh
    git branch "branch name"
```

Checking branches

```sh
    git branch
```

Chang Branch

```sh
    git checkout "branch name"
```
