## Git Intro &mdash;

### Check Git Version —

```sh
    git -v
    git --version
```

### What is Git?

- Git ဆိုတာ version control system ဖြစ်တယ်။
- ပြောင်းလဲသွားတဲ့ Record တွေအကို မှတ်ထားပေးတယ်။ ( ်everything )
- လိုချင်တဲ့ version ဆီကို recall ပြန်လုပ်နိုင်
- project တစ်ခု collaborate လုပ်မို့ လူအများကြီးကို ခွင့်ပြုပေးနိုင်တယ်။

<hr>

### Git vs Github/Gitlab

#### Git &mdash;

- Git ဆိုတာ github/lab repositories ပေါ်က code တွေကို manage လုပ်ပေးနိုင်တဲ့ tools တစ်ခုဖြစ်ပါတယ်(can use git without gitlab/github)
- Version history တွေကို သိမ်းထားနိုင်ခြင်း

#### Github/Gitlab &mdash;

- Source code တွေကို သိမ်းဆည်းထားသော နေရာ
- Project ကို online ပေါ်မှာ host အနေနဲ့ တင်လို့ရ
- ကျတော်တို့ရဲ့ code တွေကို အခြား developer တွေကို Share ပေးနိုင်
- Download and Collaborate လုပ်နိုင်

<hr>

### Important Notes

Git

- Porject တစ်ခုလုပ်တိုင်း repository တစ်ခုဖြစ်ရမယ်။ (repository တစ်ခုမှာ project အများကြီး မထည့်ရ)
- Branch တွေ တည်ဆောက်ပီး အသုံးပြုသင့်တယ် (branch တစ်ခုဟာ version တစ်ခုလို အသုံးပြုနိုင်)
- အချိန်တိုင်း remote Repo နဲ့ ချိတ်စရာမလို
