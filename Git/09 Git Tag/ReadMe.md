### Git Tag &mdash;

1. Lightwight Tags - Name only
2. Annotated Tags - Allow you to add a message explaining the tag

```sh
    git tag tag_name # lightweight

    git tag -a tag_name -m "message" # annotated
```

### Show all tags &mdash;

```sh
    git tag

    git tag --list
```

### Show calling tag name &mdash;

```sh
    git show tag_name
```

### Read Note &mdash;

```sh
    git tag -n
```

### Edit Tag Note &mdash;

```sh
    git tag -a tag_name -f

    git tag -a tag_name -f commit_no.
```

### Name old commit &mdash;

```sh
    git tag -a tag_name commit_no.
```

### Delete Tag &mdash;

```sh
    git tag --delete tag_name

    git tag -d tag_name
```
