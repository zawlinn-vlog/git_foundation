### Rename Github BranchName &mdash;

```sh
    git checkout "branchName"
    git branch -m "newBranchName"
    git branch -m "oldBranchName" "newBranchName" # oldBranchName is optional

    git push -u origin --delete "oldBranchName"

    git push -u origin "newBranchName"
```

### Delete GitHub BranchName &mdash;

```sh
    git push -u origin --delete "oldBranchName"
    git push -u origin -D "oldBranchName"
    git push -u origin -d "oldBranchName"
    git push - origin :oldBranchName
```
