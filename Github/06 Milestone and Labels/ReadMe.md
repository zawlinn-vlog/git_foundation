### Create Github Milestone and Labels &mdash;

```
    Repository ->  issue -> project
                         -> Milestone
                         -> Label
```

### Milestone &mdash;

တစ်ခုခု လုပ်စရာရှိတာတွေကို ကြိုတင်မှတ်သားထားနိုင်တယ်။ ပီးတဲ့နောက်မှာ issue တစ်ခုပြုလုပ်ပီး Milestone ကို add ပြီး ဘယ်သူကို assign ချနိုင်ပါတယ်။ assign ချတဲ့သူက အဲ issue ကို ပြင်ပီးတော့ close လိုက်ပီးဆိုရင် Milestone က ပျောက်သွားမှာဖြစ်ပါတယ်။

### Label &mdash;

Label ဆိုတာကတော့ issue ရဲ့ level ကို ဘယ်အဆင့်ထိ သက်မှတ်မလဲဆိုတာ label က သက်မှတ်ပေးနိုင်ပါတယ်။
